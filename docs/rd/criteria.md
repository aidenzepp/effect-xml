# Comparison criteria

Every spike RESULT.md scores each approach it compares against these criteria, 0 to 5 per criterion, with the evidence the "measured by" column names. Weighted totals rank approaches; a 0 on a criterion marked **gate** disqualifies the approach regardless of total. Spikes that do not touch a criterion write `n/a`, not 0.

## Fixture obligations

- Fixture files come from `spikes/fixtures/qti/` as assembled by SPIKE-00. Spikes read them and never modify them. A spike that needs a variant (re-prefixed, broken, enlarged) writes it under its own directory.
- The canonical comparator is defined once in SPIKE-03 and copied, not imported, into any other spike that needs it, to keep spikes independent. SPIKE-03 publishes it as a single file under 80 lines so copying is cheap.

## Scoring rules

- Score the approach as implemented in the spike, not as it could be after more work. Write the unimplemented part as a note.
- Evidence is a test name or a command plus pasted output. A score without evidence is treated as `n/a`.
- Report the number of tests the spike runner executed; a run that executed zero tests is not evidence.

# QTI fixture sources

The corpus is synthetic QTI 3 items authored in this repository, plus one Apache-2.0 portable custom interaction (PCI) example from Houghton Mifflin Harcourt. None of the files contains student or customer data. None of them is imported by `src/` or `test/`.

The authored files replace earlier fixtures and keep the coverage listed under Exercises. `pci-shaded-grid.xml` is byte-identical to the linked copy, apart from the kebab-case file name.

## Notes

- **`pci-shaded-grid.xml` carries its own license.** Houghton Mifflin Harcourt licenses the file under Apache-2.0 in its header comment, which is kept unchanged. Apache-2.0 section 4 requires that recipients get a copy of the license, so the full text is in [`LICENSE-APACHE-2.0.txt`](LICENSE-APACHE-2.0.txt).
- **No QTI 2 files.** Every file is QTI 3: a `qti-assessment-item`, a `qti-assessment-test`, or a content-package manifest that references QTI 3 resources. The two `conformance-*` files are the most minimal QTI 3 items, kept for contrast with the full items.
- **No CDATA.** No file in this directory contains a `<![CDATA[` section. CDATA coverage lives in `spikes/round-trip/cdata.xml`. Entities are covered here by `text-and-media.xml` and `conformance-read-by-a-rule.xml`.
- The `xsi:schemaLocation` values point at `purl.imsglobal.org` and `w3.org`. Effect's parser never fetches them, so every file decodes offline.
